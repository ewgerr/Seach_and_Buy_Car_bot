# Car_Search Bot

Короткий опис
- Telegram-бот для пошуку оголошень Auto.RIA з можливістю спостереження по областях, локальним кешем регіонів і механізмом обмеження запитів до безкоштовного API.

Швидкий старт
1. Встановіть Node.js (рекомендовано 18+).
2. Зробіть `npm install` у папці проекту для встановлення залежностей (axios, node-telegram-bot-api, dotenv).
3. Створіть файл `.env` у корені проекту з такими змінними:

```
TELEGRAM_TOKEN=ваш_токен_телеграм
AUTORIA_API_KEY=ваш_api_key_autoria
AUTORIA_RATE_LIMIT=30    # необов'язково, кількість запитів в годину
```

4. Запустіть бота:

```powershell
node bot.js
```

Основні файли
- `bot.js` — головний файл бота та обробка команд/повідомлень.
- `autoria_region_api.js` — wrapper для Auto.RIA, кеш регіонів, менеджер квоти, watch-менеджер.
- `menu.js` — клавіатури та пагінація вибору областей.
- `state.js` — просте файлове збереження стану користувачів (`state.json`).
- `regions_fallback.json` — локальний список регіонів з `id` і `name` (використовується коли API обмежено).
- `regions_cache.json`, `avg_cache.json`, `rate_state.json` — файли, які створюються під час роботи для кешу та збереження квоти.

Команди Telegram
- `/start` — головне меню.
- `🔎 Новий пошук` — задати ціну та вибрати область (пагінована inline-клавіатура).
- `⚙️ Налаштування` — налаштування кількості результатів.
- `⏱ Увімкнути спостереження` — вмикає watch по області; після вибору області введіть максимальну ціну.
- `⏹ Вимкнути спостереження` — вимикає watch по області.
- `/quota` — показати поточний стан спільної квоти API (used/limit, час до скидання).
- `/notify_on` — підписатися на повідомлення про скидання квоти (отримуватимете повідомлення, коли ліміт скинуто).
- `/notify_off` — відписатися від повідомлень про скидання квоти.
- `/set_interval <sec>` — встановити інтервал спостереження (секунди, від 60 до 3600). Наприклад: `/set_interval 300`.
- `/refresh_regions` — примусово оновити кеш регіонів (намагається оновити з API або очищує локальний кеш).

Поводження з лімітом Auto.RIA
- Auto.RIA на безкоштовному ключі часто повертає HTTP 429 з помилкою `HourOverlimit` (обмеження запитів в годину). Бот реалізує:
  - локальний persistent-лічильник квоти (`rate_state.json`) і перевірку `canMakeRequest()` перед виконанням запиту;
  - повідомлення користувачів, які підписались, коли квота скидається (`quota_reset`);
  - обмеження polling для watch: за замовчуванням мінімум 300 с, щоб зменшити навантаження;
  - використання `regions_fallback.json` з локальними `id` щоб уникнути запитів при виборі області.

Як працює квота
- Файл `rate_state.json` зберігає `windowStart` (мілісекунди) та `countUsed`.
- Після першого успішного запиту починається година (вікно). Після використання всіх `AUTORIA_RATE_LIMIT` запитів бот очікує скидання вікна; при скиданні бот емитить подію `quota_reset` і робить одноразову перевірку активних watch-ів.

Поради
- Якщо плануєте багатьох користувачів — рекомендовано отримати paid API-ключ у Auto.RIA або додати кілька ключів і влаштувати чергу/балансування.
- Щоб покращити локальні оцінки цін, бот записує знайдені ціни у `avg_cache.json` і використовує локальну середню, якщо API unavailable.

Розробка та відладка
- Для швидкої перевірки логів просто запустіть `node bot.js` і дивіться консоль — там є детальні повідомлення про 429 і заголовки відповіді.

Контакти та подальші кроки
- Можу додати: адміністративні команди (змінювати пріоритети користувачів), round-robin розподіл запитів, або балансування між кількома API-ключами. Скажи, що зробити далі.
